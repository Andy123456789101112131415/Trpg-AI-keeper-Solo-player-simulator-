# 地点 6：奥戴尔家

> 本文件为「程序化剧本」：每个触发条件下的输出内容均写死在此，玩家触发后才释放。AI 仅据此润色语气，不得新增或改动事实。

## 场景：进入描写

奥戴尔女士的家孤零零地蹲在死巷尽头，门廊的木板翘起，檐下悬着一张半脱的蛛网，在风里微微颤动。所有窗户都黑着，窗帘拉得严丝合缝，不透出一点光。你抬手敲门，指节落在门板上，声音很快被四周的寂静吞没——没有人应门。整栋房子安静得吓人，像把呼吸都屏住了在等着什么。

### [NEIGHBOR] 询问邻居关于奥戴尔的近况
**输出**：邻居说，上次看到奥戴尔女士是几天前。她平时不怎么出门，只在深夜散步。

### [WINDOW] 搜查房屋周围
**输出**：屋后窗户的锁扣被弄坏，窗台有爪印，窗下泥土有蹄印。（若从金博尔家沿蹄印追踪而来，无需检定即可发现这些细节。）

### [SMELL] 进入屋内
**输出**：你推门进屋，一股酸臭味立刻扑面而来，像有什么东西死在了里面，那股气味明显是从地下室的方向飘上来的。这是一栋两层的木质小洋房：一楼是客厅和厨房，陈设蒙着薄灰；一道狭窄的木楼梯通上二楼。借着窗外透进的微光，你隐约看见二楼的楼梯口旁，有一间卧室。此外，一楼深处还有一扇通往地下室的小门。

### [DIARY] 上二楼搜查床头柜
**输出**：奥戴尔女士床头柜上放着一本日记，记述了她的心路历程，共四段：

- **1922年（日期被涂抹）**：昨晚深夜，我遭遇了人生中最恐怖的一幕。我无意中漫步到镇上的墓地里，注意到远处有一个人影（或几个？）。我以为那是谁家游手好闲的小子，便走近了几步，直到我意识到自己错了——那不仅不是孩子，那根本就不是人类！我几乎还没来得及看清那恶魔狗一样的鼻子和分开的脚掌，就赶紧逃回了家。幸好比尔已经睡着了，我不用解释自己的行踪，因为我觉得自己可能连一句连贯的话都说不出来。我甚至一度以为那只是个梦。今天早上，我决定去墓地，去我曾看到它的地方。我花了一整天寻找任何证据，直到发现一座古老的陵墓，门微微开着。里面本该是石质的地面，现在却露出了土壤。这些恶魔在亵渎坟墓吗？
- **1923年6月27日**：食尸鬼！我终于知道那些可憎之物的名字了。我不能冒险让这些恶魔知道我已经发现了它们——谁知道落在那些生活在泥土和骨头之间的生物手中，我会遭遇怎样的命运，更别提它们的饮食习惯。得知它们就生活在我们脚下、毫无疑问是地狱的产物，我担心它们随时都可能找上门来！我们必须找到一种方法来保护自己，终结这种前所未见的威胁。
- **1926年10月15日**：终于，我找到了能够从那些邪恶力量手中拯救地球的办法。我得到了一本据说非常古老的神秘巨著的副本，里面全是关于恶魔的记载。这本书是从古法语翻译过来的，而且写得非常杂乱无章，我需要一些时间来研究其中的所有秘密。
- **1927年（日期被涂抹）3日**：终于到了这一刻！我已经发掘出了这本书以及这个世界的秘密。这本书不仅包含了我所追寻的所有知识，甚至包含了我要找的解决方案——它里面有一个用于联系恶魔的咒语，我可以利用它找到通往那个地下世界的途径。一旦到达那里，我将利用那些书页赋予我的另一种力量，召唤一个仆从来保卫地上的正义世界。

你想再找找那本神话书，却一无所获——书已经被奥戴尔一起带进了隧道。

## 检定

### [SNEAK] 悄悄靠近地下室（潜行检定）
- 技能：潜行（**夜晚难度为困难**）
- 触发：玩家试图悄无声息地靠近地下室/摸向那扇通往地下室的门。
- **成功**：你屏住呼吸，贴着墙一点点挪到地下室门口，没有发出一丝声响。门内传来极轻的、不规律的呼吸声——里面有什么活物，而且它还没有察觉到你。
- **失败**：你的鞋底在木地板上蹭出了一丝响动，在死寂的房子里格外刺耳。地下室里那原本极轻的呼吸声骤然停住了——对方已经知道有人来了。

### [HIDE] 打开门看到食尸鬼后躲藏 / 退回（躲藏检定）
- 技能：躲藏（**夜晚难度为困难**）
- 触发：打开地下室的门、看到食尸鬼后，玩家选择躲藏 / 退回暗处 / 悄悄退离避开。
- **成功**：你眼疾手快，轻轻掩回那扇门后，缩进旁边的一丛阴影里，屏住呼吸，纹丝不动。片刻后，那佝偻的身影朝门口的方向张望了几下，喉咙里挤出一声含混的低吟，似乎认定只是自己多心——随即，它又缓缓缩回了楼下的黑暗里，再没了声息。
- **失败（被它发现，但它主动讲出故事）**：你刚退后半步，脚下的旧木板便"吱呀"一声。那身影猛地停住，缓缓转过头来——暗处，一双深陷、发亮的眼睛直直望向你。可它没有扑上来，也没有嘶吼，只是看清了你并没有举起武器。它缓缓直起身，喉咙里先滚出一声如释重负的叹息，随即用沙哑的、带着悔意的声音开了口，把它的遭遇一五一十讲给你听：奥戴尔女士曾联络它，说需要它帮忙——它信了；此后，它与奥戴尔每夜定期在墓地附近会面；直到那一晚，奥戴尔突然用枪劫持了托马斯，把他拖进了食尸鬼隧道。它反复说自己错信了莉拉·奥戴尔，又悔又恨，恳求你进入隧道，把托马斯救出来；它还低声提醒你，奥戴尔一定在筹划什么，而那个计划，也许就写在她的日记里。

### [SAN_SEE] 直面食尸鬼道格拉斯的真容（理智检定）

### [DOUGLAS_DOOR] 打开地下室的门（遭遇触发点）
- 触发：玩家打开地下室的门 / 推开地下室门 / 打开那扇通往地下室的小门。
- **输出**：你握住门把，缓缓推开那扇通往地下室的小门。门轴发出干涩的呻吟，一股更浓的酸臭味混着湿土的气息迎面扑来，几乎呛得你睁不开眼。借着微弱的光，你看清门后通往地下的楼梯上，蜷着一个佝偻的身影——灰败的皮肤，深陷的眼窝。屋里静得可怕，那个身影似乎还没有察觉到你。

## KP 贴士

**道格拉斯遭遇（已程序化的分支流程）：**
- 食尸鬼道格拉斯**保持安静、不主动发声**，屋内探索阶段（SMELL / UPSTAIRS / DIARY）绝不出现它的声音。
- **道格拉斯是受害者、是求助者**：只要玩家不攻击它，它就会主动讲出自己的遭遇、恳求救援托马斯。
- 玩家打开地下室的门（DOUGLAS_DOOR）→ 看到蜷在楼梯上的食尸鬼（关键决策点）。
- 此时分析玩家的选择，两条路径：
  1. **攻击** → DOUGLAS_ATTACK（`combat`）：触发战斗模拟器。
  2. **不攻击** → 道格拉斯不盘问，**直接主动讲出自己的故事**（DOUGLAS_STORY，含自我介绍）：
     - 躲藏/退回（HIDE 检定）：成功→道格拉斯没发现，缩回楼下（这轮错过）；失败→它发现你没攻击，直接开口讲出完整故事。
     - 不躲也不攻击（站在原地/喝问/表明来意）→ 道格拉斯直接讲出完整故事（DOUGLAS_STORY）。
- 若玩家是在墓地陵墓被臭晕、被道格拉斯救回（DOUGLAS_RESCUE）：道格拉斯先自我介绍、说明这是奥戴尔家地下室、讲述他找到并带回你的经过，再讲出完整故事。

**原模组细节（供 KP 裁量，程序暂未做时间/潜行区分）：**
- 道格拉斯白天在地下室睡觉，潜行失败或未静音移动会惊醒他；晚上他醒着，需困难潜行否则他知道有人进来。
- 若曾在"追书人"里与他有交情且向楼下喊话，他会听出声音主动现身。
- 若调查员一直没去奥戴尔家：方向正确→让道格拉斯在仪式室与奥戴尔战斗；方向错误→道格拉斯夜间行动时发现调查员，暗中送来日记（带泥土和动物毛发），可用追踪检定循迹找到奥戴尔家。
